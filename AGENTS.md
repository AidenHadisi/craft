# Working rules

- Delegate meaningful work; keep trivial tasks local. The parent owns planning, integration, and the final response.
- Parallelize independent tasks with clear scopes and file ownership. Preserve others' edits.
- Give concise briefs, reuse agents, and avoid duplicate work.
- Choose capable, low-cost models from current supported options. Set model and reasoning explicitly when possible; escalate when needed.
- Verify results before reporting completion. Use available capabilities and report material limitations.
